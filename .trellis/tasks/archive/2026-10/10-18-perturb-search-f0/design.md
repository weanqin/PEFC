# design — 虚拟扰动范式×响应度量低成本搜索（v1-fmt θ\*·fold0）

> 预注册文档：候选集 / r0 / gates / 选择规则 / 探针选择一经本文件定稿 + experiment.md 首个 Run 块登记即钉死；主 Run 后最多一次「档位级」调整（K、窗数）并登记，候选定义不得中途改（prd 口径纪律）。
> **增补修订（2026-10-18，主 Run 启动前，用户拍板）**：加入 **Gate D 单调性筛选**（§5）与 **r 网格**（§3）——批构造扩 r 维、A/B/C 取 r0 切片不变，属预注册范围内正式扩界（非中途改口径）。

## 1. 总览与「不做」清单（速度设计）

**流程一句话**：冻结 v1-fmt θ\* → 阶段一（固定输入探针，扫 6 个度量候选，选 M\*）→ 阶段二（固定 M\*，扫 6 个范式候选，选 P\*）→ 每候选以 r0 为中心的 5 点 r 网格（A/B/C 取 r0 切片、Gate D 全网格单调性审查）、每窗一次 CRN 批采样。

**不做**（prd R5/R7；**范围修订 2026-10-18 用户拍板**）：零训练/微调；不做多种子；~~不做 r 网格（单强度）、不做剂量-响应与单调性（登记为范围外局限）~~ → **增补 Gate D 单调性筛选**（r 网格仅用于该审查，A/B/C 仍 r0 单点；完整剂量-响应标定与 r\* 搜索仍范围外）；不做统计检验套餐（gates 为预注册阈值判定）；不做 EC 比较、参考连接组、5-fold；可视化仅 1–2 张诊断图（scorecard 汇总表为主）。

**规模预算**：3 受试者 × 8 窗 = 24 窗，K=16 CRN 样本/窗，seed=2026。批形状（r 网格化后）：阶段一 559 行（1 baseline + 62 源 × 9 格点 = G4+N5）、阶段二 1737 行（1 + 62 × 28 格点）。v1 干路 d_model=16（小模型）+ chunk_bk 控显存，预计每阶段 GPU 十分钟级（r 网格化行数约 ×4.7；超 AC6 30 min 预算则如实照登）；实测登记。

- **CRN 契约**（沿 perturb-ec-pipeline.md / reproducibility.md）：`EulerSampler.sample(x, K, eps, eta)` 显式噪声逐窗一组（`torch.Generator.manual_seed(SEED + win_idx)` 先 eps 后 eta），baseline 与全部变体同批共享；每窗**一次** sample() 调用；r=0 逐位恒等由单测锁定（**恒等断言只在同批形内成立**——跨批形 cuBLAS/mamba 核不保证逐位相等，pipeline.md §1）。**win_idx 规则（钉死）**：win_idx = 受试者 manifest 顺序 × 每例前 8 窗的固定枚举序（例 #1 窗 0–7 → win_idx 0–7，例 #2 → 8–15，例 #3 → 16–23）；两阶段窗枚举一致 ⇒ **同窗 eps/eta 张量跨阶段逐位相同**（噪声级配对，硬断言）；baseline **输出**跨阶段只作紧容差 allclose 对照（rtol=2e-6，逐位相等如实测得则照登），不作逐位门。crn_noise / 批构造为**本任务自实现**（读自身 config；不复用 perturb-ec-v1 的 build_variant_batch/crn_noise——二者读旧任务 config 网格与路径）。
- **窗集**：fold0 test 受试者 manifest 顺序前 3 例 × 每例数据集顺序前 8 窗（确定性，不随机）。
- **入口脚本 BLAS 护栏**：numpy 导入前 setdefault 限 8 线程（16 核 cgroup 契约）。

## 3. 输入端候选（6 类范式 × 每类一个代表；源通道 A，past 全段 384 样本）

r0 定标原则（预注册）：每算子取自身自然单位下「中等、明显超阈但不显著外推」的单一值；共同幅度尺度 σ_A = 该窗源通道 past 段 std（z-score 后数据 σ_A≈1，仍逐窗实算）。r0 唯一作用 = 让响应离开地板进入可测区。

**Gate D r 网格（增补，用户 2026-10-18 拍板）**：5 点倍率梯 {0.25, 0.5, 1, 2, 4}×r0 + 逐算子上限钳制（G 钳 0.32 = 外推警示界、L 钳 1.0 = 语义界——r>1 变反相信号；N/O/P/B 无已登记语义界不钳，高倍率外推警示随注记照登），钳制后升序去重：**G {0.0625, 0.125, 0.25, 0.32}、N {0.125, 0.25, 0.5, 1, 2}、O {0.25, 0.5, 1, 2, 4}、P {0.75, 1.5, 3, 6, 12}、L {0.125, 0.25, 0.5, 1}、B {0.25, 0.5, 1, 2, 4}**（r0 本点并入网格不重复行；字面网格 = config.R_GRID 预注册钉死）。**r_2 恒等（用户 2026-10-18 口径确认）**：全部范式 r0 均居格点序 2 = 网格中位格点 **r_2**（倍率梯中位 mult=1.0；G/L 钳制去重后仍居序 2，即去重格的上中位、非算术中位）——A/B/C 评估点 = r_2 = r0 本点，无插值无额外行；单测 ⑧ 锁定。

| # | 类别 | 代表实现（定义式） | r0 | 一句话理由 / 注意 |
|---|---|---|---|---|
| G | 乘性增益 | `x_A ← (1+r)·x_A`，past 全段 | 0.25 | 现行 A 案参照（perturb-ec-v1::apply_gain 已实现）；r≥0.32 外推警示沿前任务 design §2.1，r0 在界内 |
| N | 加性带限噪声 | `x_A ← x_A + r·σ_A·g(t)`，g = 1–40 Hz 带限白噪固定 seed 波形（RMS=1） | 0.5 | 直接注入方差，perturb-and-record 标准形态；前任务 B 案文档预留的首次实现 |
| O | 恒定偏置 | `x_A ← x_A + r·σ_A`（全段常数） | 1.0 | 最简加性（DC 平移）；数据 1–40 Hz 带限下 DC 属外推输入，解释随附警示 |
| P | 瞬态脉冲 | `x_A ← x_A + r·σ_A·h(t)`，h = 20 样本（80 ms）汉宁脉冲，中心 past 末端 −40 样本 | 3.0 | 瞬态刺激 → 时间形态可辨（M-time 天然搭档）；剂量高因持续时间短 |
| L | 钳位损毁 | `x_A ← μ_A + (1−r)·(x_A − μ_A)`，μ_A = 该窗 x_A 均值 | 0.5 | 损毁式（信号衰减 50% 向自身均值收缩），与增益互补方向；数值安全不外推 |
| B | 带限增益 | `x_A ← x_A + r·BP_{8–13Hz}(x_A)`（α 带分量增益 1+r） | 1.0 | 频率选择性：检验分频带传导（谱域度量敏感探针）；BP 零相位 |

全部算子实现契约：只动通道 A 逐元素、其余通道逐位不动（单测断言）；**r==0 短路返回 clone（预注册，规避 L 减加往返与 ±0.0 翻转的浮点陷阱；L 实现代数形式 `x_A − r·(x_A − μ_A)`）**；返回新张量。变体批构造沿 perturb-ec-v1::build_variant_batch **同构**（行 0 = baseline，其后源 A 主序、范式/探针次序；本任务自实现读自身 config）。

**新算子实现参数（预注册钉死）**：N 的 g(t) = 固定 seed FFT 域 1–40 Hz 掩码生成的 384 样本波形、带限后 RMS 重归一到 1、**全局共享单波形**（跨 (A, 窗) 不变）；B 的带通 = Butterworth ≤6 阶 + scipy filtfilt 零相位（默认 padlen，384 样本下安全；scipy 1.18.1 已在 environment.md 登记）。

## 4. 输出端候选（6 类度量 × 每类一个代表；逐有向边 A→B 标量）

统一输入：同窗同 CRN 配对样本 δ_k = perturbed_k − baseline_k（k=1..K，靶通道 B 时间序列）+ baseline 行自身统计。z-score 后数据，度量值无量纲。

| # | 类别 | 代表实现（定义式） | 一句话理由 / 注意 |
|---|---|---|---|
| M-RMS | 时域幅度（参照） | `RMS_{k,t}(δ)/s_{w,B}`，s_{w,B} = baseline 生成分布靶通道自身波动尺度 | 现行 D（response.py 同构）；作基准线 |
| M-PSD | 全带谱距离 | `mean_k ‖log10 PSD_k^pert(B) − log10 PSD_k^base(B)‖₂`，Welch 1–40 Hz（ε 地板） | 谱域完整描述；对波形相位不敏感 |
| M-band | 分带功率 | 五带（δ1–4/θ4–8/α8–13/β13–30/γ30–40 Hz）Δlog10 功率，逐边取 \|Δ\| 最大带为主带（身份照登） | EEG 频带可解释性强；比全带更聚焦 |
| M-env | 包络幅度 | α 带 Hilbert 包络均值相对变化 `\|mean_k env^pert − mean_k env^base\| / mean env^base`（靶通道） | 振幅耦合载体（连接文献常用） |
| M-FC | 相关结构 | 未来段通道-通道相关矩阵行向量变化 `‖R_rowB^pert − R_rowB^base‖₂` | 网络级/同步响应；注记：依赖全通道（网络态度量非纯靶响应） |
| M-time | 时间形态 | `\|\bar δ(t)\|` 前 32 样本（128 ms）均值为主标量；全段峰值与早期/全段比值照登 | 瞬态探针天然读出；判响应起点与时程 |

## 5. 噪声地板与 scorecard（gates + 选择规则，预注册）

**度量实现参数（预注册钉死）**：M-PSD/M-band 共用 Welch（fs=250、nperseg=128、Hann 窗、50% overlap ⇒ bin 宽 1.95 Hz；**bin 中心落入带内**为归属规则，δ 带 1–4 Hz 仅 ~1–2 bin、方差大属已知照登；log10 前加 ε=1e-12 相对地板）；M-env 的 Hilbert 在 128 样本短段上有边缘效应（pert/base/null 同算子施加，偏差部分抵消，注记照登）；M-FC 取**逐 k 相关阵后均摊**（128 时间点 > 62 通道，估计量可行）；null 地板**逐靶通道 (B) 计算、逐边 (A→B) 复用**（M-RMS/PSD/env/band 的 null 不依赖源 A）。

**null 地板**：baseline 行 K=16 拆 8+8 两半，按各度量同构计算两半间「距离」→ 每窗每边一个 null 值；**逐边 24 个 null 值取 std**（统一口径，不用中位）。**z = D_edge / null_std_edge**。保守性注记：split-half(8+8) 零噪声距离约为 D_edge（K=16 配对）采样噪声的 2 倍宽，gate 实际偏严（保守方向，可接受照登）。

| Gate | 判据 | 针对什么 |
|---|---|---|
| A 敏感性 | median_edges(z) ≥ 2（z≥2 边占比作登记项，不作门——median≥2 已蕴含 ≥50%） | 响应是否离开采样噪声地板 |
| B 特异性 | 自跨比 median(D(A→A))/median(D(A→B≠A)) ≥ 2；Spearman(D, 通道距离) 点估计照登（负值加分、不作硬门） | 直击前次失败（自跨比 1.27× 弥散） |
| C 稳定性 | 跨受试者 split-half（**预注册指派：例 #1+#2（16 窗）vs 例 #3（8 窗）**）边值秩相关 ρ ≥ 0.5；单划分 2v1 不均衡、无重采样属已知薄弱性照登 | 筛选结论可复现 |
| **D 单调性（增补，用户 2026-10-18 拍板）** | **仅改变 r**（同批一次 sample() ⇒ 跨 r CRN 逐位配对）下，\|Δ\| 聚合曲线（逐 r：D_edge = 24 窗 median → offdiag 边池 median）随 r 单调不减——**曲线相邻步 100% 不减才过**；「不减」含等号（浮点护栏 rtol=1e-9）；逐边单调占比作登记项不作门；违反情形（步序、两端 r、曲线值、相对降幅）明细落盘 | r\* = inf{r: Δ(r)≥τ} 的可定义性（Δ 须为 r 的良态单调函数）——不满足即指出违反情形 |
| 成本/可解释性 | 每候选实测秒数 + 一句话定性注记 | 同分决胜，不作门 |

**Gate D 增补口径（用户 2026-10-18 两轮拍板）**：A/B/C 判据不变、一律取 **r = r0 格点切片 = 网格中位格点 r_2** 评（与原单强度预注册逐位一致；D 用全网格（§3 r 网格）。阶段一 D 逐探针分别判定（至少一探针过线，同 Gate A 口径）；阶段二每范式独立判定。聚合曲线基于**度量指标变化大小的绝对值 |Δ|** 聚合（D_edge 先取 |·| 再 24 窗 median → offdiag 边池 median）；**逐边通过比例（逐边曲线单调的 offdiag 边占比）记录并报告**（scorecard.csv `gateD_edge_mono_frac` 列 + summary「D 边单调占比」列，登记项不作门）。

**选择规则**：过全部**四**门（A/B/C/D）者中按 **Gate B 主排序 → Gate C → 可解释性 → 成本** 选出 M\*/P\*（特异性是已知失败模式故为主序）。**全候选不过线 = 如实阴性**：报最佳可得候选 + 逐 gate 缺口数值与一句话诊断，不宣称成功（沿 10-17-perturb-ec-f0 AC6 纪律）。

## 6. 两阶段流程

**阶段一（定度量 M\*）**：固定输入探针 = **{G(r0=0.25), N(r0=0.5)} 双探针**（预注册推荐）。理由：增益已知可能弱，单用 G 恐全体度量地板化、筛选退化；N 保底 elicitable；G 保留因其为现行口径、响应特征本身是信息。批 = 1 + 62×9 = 559 行（G 4 格 + N 5 格），一次 sample()/窗（跨 r CRN 逐位配对）。度量得分：两探针**分别**过 Gate A 与 Gate D（各至少一探针过线）；Gate B/C 按两探针合并边池计算（B/C @ r0 切片）。→ 选 M\*。
- *备选已作废*：~~严格单形式备选~~——**用户 2026-10-18 拍板：双探针 {G, N}**（单探针 N 备选与单探针 G 方案均不再启用）。

**阶段二（定范式 P\*）**：**度量集 = {M-RMS, M-PSD, M-time}（用户 2026-10-18 拍板——阶段一如实阴性无单 M\*，取 Gate A 最强 M-PSD / Gate B 唯一过线 M-time / 现行基准 M-RMS 三度量继续；「单 M\*」预注册规则的显式偏离，登记在案）**。批 = 1 + 62×28 = 1737 行（六范式各自 r 网格；G、N 再评入列），一次 sample()/窗，同 win_idx 复用 eps/eta（**硬断言 = 同窗 eps/eta 张量跨阶段逐位相同**；baseline 输出紧容差 allclose rtol=2e-6 对照，逐位相等如实照登——跨批形无逐位保证，见 §2）。六范式 × 三度量逐 (范式, 度量) 按 §5 scorecard 打分（A/B/C @ r0 切片 + D 全网格）；**P\* 逐度量独立判定**（各度量内过线者按选择规则排序），联合 {P×M} 终选以 3×6 矩阵呈报留用户拍板；**结论限定「各自 r0 下」**（A/B/C @ r0 单点 ⇒ P\* 实为「范式×r0」联合选择，不得表述为全域最优范式；Gate D 已在各自 r 网格验单调，不改变该限定）。

**执行序**：B0 骨架+单测 → B1 smoke（1 窗阶段一批，跑通+耗时登记）→ B2 阶段一主 Run（24 窗）→ M\* 判定 → B3 阶段二主 Run → P\* 判定。B2→B3 自动衔接；阴性/异常即停并呈报。

## 8. 风险与已知边界

- **r 依赖局限（2026-10-18 修订）**：Gate D 已查 5 点网格上 |Δ| 聚合曲线单调性，但 A/B/C 仍 @ r0 单点评、完整剂量-响应标定与 r\* 搜索仍范围外（后续任务以 P\*×M\* 补）。各算子窗 RMS 足迹差约 4×（B 最小 ~0.15–0.27σ，有地板化风险）——**B 若败 Gate A，先查该窗 α 带功率占比再判类别死刑**；结论一律「各自 r0 下」表述，不得称全域最优。钳制格顶点（G 0.32 / L 1.0）读出属界内最大剂量证据，N/O/P/B 高倍率格点外推警示随注记照登。
- **输入端边界**：候选均为输入层扰动，不含内部表示扰动（框架术语表「输入或内部表示」中的后者未测，机理登记显示跨通道响应仅经速度网络单通路）——阴性结论不得引申为「输入端无解」。
