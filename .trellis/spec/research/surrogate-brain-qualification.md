# 代理脑合格性检验规范（Study I）

**适用范围**：路由为 `study1`（EEG 代理脑，框架 Study I）的任务——凡涉及代理脑模型训练、模型选型对比、或固定 θ=θ\* 前的验收判定，必须依据本规范执行检验。任务在 1.0b 分类为 `study1` 后，1.3 配置 context 时须把本文件加入 `implement.jsonl` 与 `check.jsonl`。

**定位**：本规范回答框架核心四问中的 **Q2（该模型能否作为 EEG surrogate brain？）**。检验的是 Surrogate Brain Validity；未来预测/生成质量（Q1）是相关但独立的问题，两类结论在 experiment.md 中分开陈述，不得混写（框架文档 §7.3）。

## 检验指标

指标口径一经任务确认不得中途更换；每个指标的三要素登记与统计汇报纪律沿用 [evaluation-calibers.md](./evaluation-calibers.md)。指标 1、3 的通过标准**已回填（2026-10-16 用户拍板，首次回填消除占位）**；后续变更按 evaluation-calibers 的口径变更纪律执行。

### 指标 1：生成数据与真实数据的功能连接（FC）一致性

> **口径变更 v2（2026-10-12，用户指定）**：FC 矩阵由 **Pearson 相关**计算（经典无向 FC），两组矩阵展平后比较。**v2.1（2026-10-12，用户指定）**：显著性口径由「受试者级配对 bootstrap 95% CI」改为**逐受试者一致性值的单样本双侧 t 检验 p（df=受试者数−1）**；v2 CI 结果保留于各任务 Run 记录原口径不动。原 v1 定义（Granger 因果计算功能连接）保留为**补充参考**口径——GC 为有向度量，反映滞后动力学保留，与零滞后 Pearson FC 互补。归因提示：零滞后 FC 的相似性可能部分来自模型先验注入的空间结构，结论陈述时须注明（参见各任务指标 4/空间归因诊断，如有）。

| 要素 | 口径（v2.1） |
|---|---|
| 定义 | 测试集上分别对**模型生成的 EEG** 与**真实 EEG** 用 **Pearson 相关**计算 FC 矩阵（逐受试者计算后组内平均，两组完全相同流程）；将两组 FC 矩阵按**相同的通道/节点顺序**取上三角（对角剔除）展开为一维向量，计算 **Pearson 相关**与 **Spearman 相关**（点估计基于组平均矩阵），并给出显著性 p：**逐受试者一致性值（r_s/ρ_s）的单样本双侧 t 检验（H0: 均值=0，df=受试者数−1）** |
| 数据切分 | 测试集（默认 future-only 段，随任务 design 登记） |
| 聚合方式 | 逐受试者 FC → 组内受试者平均 → 每组一个矩阵后比较；显著性检验单位 = 受试者（逐受试者一致性值） |
| 通过标准 | **组平均 Pearson r ≥ 0.95（2026-10-16 用户拍板）**；显著性辅助口径：逐受试者 t 检验 p < 0.05 |

实现口径声明要求：FC/参考度量的计算参数（生成侧确定性采样 seed、bootstrap 次数与 seed、通道顺序、对角处理）在生成组与真实组必须完全一致，并在 experiment.md 的 Run 配置中登记；补充参考口径（GC 的模型阶数、窗长等）同样两组一致并登记；本表未覆盖的实现细节须显式声明且任务内保持一致。

### 指标 2：生成 EEG 输出的人工视觉检验

| 要素 | 口径 |
|---|---|
| 定义 | 将模型生成的 EEG 输出可视化，供用户进行人工视觉检验 |
| 数据切分 | 测试集 |
| 聚合方式 | 不适用 |
| 通过标准 | 用户人工视觉检验通过——**由用户判定，AI 不得代为判定「通过」** |

### 指标 3：生成数据与真实数据的 PSD 相似性

| 要素 | 口径 |
|---|---|
| 定义 | 测试集上分别计算**模型生成 EEG** 与**真实 EEG** 的功率谱密度（PSD），并将两者可视化对比，判断是否相似 |
| 数据切分 | 测试集 |
| 聚合方式 | 默认按测试集整体计算；如需按样本/被试/折聚合，按 evaluation-calibers 既有口径处理并显式声明 |
| 通过标准 | **低频判读窗（δ–β = 1–30 Hz）组平均谱 mean \|Δlog10\| ≤ 0.5 且 PSD 曲线形态目视一致（2026-10-16 用户拍板；频段边界 2026-10-17 适配登记）**；高频照登段 = **40 Hz–Nyquist（fs 耦合：500 Hz→40–250、250 Hz→40–125）**因真实侧功率数值地板不设阈值，但数值必须照登。判读窗下沿取 1 Hz：真实侧带通（edra/edra-fmt 均 1–40 Hz）使 <1 Hz 为滤波地板不得入口径窗；全频段 mean \|Δlog\| 类统计量在「生成侧未滤波」口径下被地板区主导，不作判读依据（evaluation-calibers fmt 范式口径） |

## 判定流程

1. **触发条件（何时检验）**：同时满足以下两项时，对模型进行检验（即核算本规范三项指标）：
   - 任务路由为 `study1`；
   - 模型使用**真实 EEG 数据**（非合成数据）训练完毕（指通过第 2 条门禁后的 **5-fold 完整训练**完毕）。

   触发后即核算指标 1、3 并产出指标 2、3 所需的可视化，登记到 `{TASK_DIR}/experiment.md` 对应 Run 块（目的/配置含指标口径/结果含数值与图路径/结论）。用合成数据训练的模型（调试、方法验证等 run）**不触发**本检验；此类 run 的质量结论与代理脑合格性分开陈述，不得混写。
2. **前置验证门禁（5-fold 训练前）**：study1 任务必须先在 **fold0、单 seed** 条件下完成前置验证——按本规范三项指标核算并落盘（Run 块标注「前置验证 · fold0 · 单 seed」）——经**用户明确同意**后方可进入 5-fold 完整训练；未经同意不得启动 5-fold。划分与 fold 定义见 [data-pipeline.md](./data-pipeline.md)。
3. **固定 θ=θ\* 的门禁**：框架 14 步流程要求「验证代理脑」先于「固定代理脑参数」。固定前必须完成本规范全部三项检验并将结果落盘；指标 1、3 按已回填的通过标准判定，指标 2 由用户结合可视化人工判定。
4. **未通过检验前**：不得宣称「代理脑合格」，不得固定 θ=θ\* 进入 Study II 扰动实验（见 `.trellis/research/context.md` 守护项「Stage 顺序」）。
