# 数据集契约 — <数据集名>

> 每个数据集一文件。事实以实测为准：跑过验证脚本 / 核对过原始文件才算「实测」；不确定的写「待验证」并标注日期。

## 1. 来源与版本

- 来源 / 获取方式、获取日期、原始规模（文件数 / 被试数 / 样本数）
- 版本标识（v 号或日期快照）；与其他版本的关系与**不可互换处**

## 2. 组织与字段

- 目录结构、文件命名规则、关键字段 schema（形状 / 类型 / 单位 / 采样率）
- 分组 / 标签口径：**分组的唯一依据是什么**，哪些表象（如文件名前缀）不可作依据

## 3. 预处理契约（若有）

- 管线步骤与关键参数（参考 / 滤波 / 分段 / 剔除规则等口径）
- 产物路径、manifest / qc 字段含义、通过率与剔除统计

## 4. 已知坑（实测沉淀）

- 坐标 / 单位 / 通道序 / 工具库版本相关行为差异等易错点
- 每条坑附证据：哪次实测、什么现象、正确做法

## 5. 下游消费规则

- 允许的筛选口径（如按 manifest qc 字段过滤）、禁止的用法
- 变更本契约任何口径 → 逐项排查对下游的影响并告知用户后方可生效
