# 实验二：Frozen-FM 逐层扰动传导审计

基于实验一，我建议**只做一个实验：冻结现有 DEVAE + FM + Decoder，做"逐层 cross-channel perturbation transmission audit"**。

这是当前信息增益最高的，因为实验一已经基本排除"GraphMixer 本身不会跨通道交互"：W-only 与 Dense 在远程 teacher 上分别达到 $R^2=0.988/0.974$，真实 FM 中 $W$ 也确实被训练成了大而稠密的 off-diagonal 矩阵。 现在真正未知的是：

$$
\boxed{\text{source perturbation 从进入真实 FM 开始，究竟在哪一层消失？}}
$$

## Experiment 2：Frozen-FM Layerwise Perturbation Transmission Audit

**不重新训练任何模型。** 完全使用当前造成 diagonal-$R$ 的 checkpoint。

对 source $a$ 施加与 I–L 完全相同的同步扰动：

$$
z_{\rm obs,a}^{\pm} = z_{\rm obs,a}\pm\delta,\qquad c_{\rm obs,a}^{\pm} = c_{\rm obs,a}\pm\delta,
$$

其中

$$
\delta = rL_{\rm ref}\xi.
$$

baseline / ($+$) / ($-$) 保持相同 nuisance randomness。

但是这一次不要只看最终：

$$
R_{a,b}(r).
$$

而是在网络内部**逐层截取响应**。

对于每个 $a\neq b$，记录四层：

$$
\boxed{
z_{\rm obs} \rightarrow h_{\rm mixer} \rightarrow v_\theta \rightarrow \hat z_{\rm fc} \rightarrow \hat x_{\rm fc}
}
$$

定义归一化敏感度，例如：

$$
G^{mix}_{a,b} = \frac{ |h^{+}_{mix,b}-h^{-}_{mix,b}| }{ 2|\delta| },
$$

$$
G^{vel}_{a,b} = \frac{ |v^{+}_{b}-v^{-}_{b}| }{ 2|\delta| },
$$

$$
G^{roll}_{a,b} = \frac{ |\hat z^{+}_{fc,b}-\hat z^{-}_{fc,b}| }{ 2|\delta| },
$$

最后仍计算现有的：

$$
R_{a,b}(r).
$$

重点不是绝对值，而是观察：

$$
G^{mix} \rightarrow G^{vel} \rightarrow G^{roll} \rightarrow R.
$$

---

## 必须加一个很小但非常关键的双臂设计

同一个实验里只换**扰动方向**，幅度严格匹配。

### Arm A：当前 DE 扰动

$$
\delta_{\rm ref} = rL_{\rm ref}\xi.
$$

就是现在造成 $R_{\rm off}\approx0$ 的 perturbation。

### Arm B：data-aligned perturbation

从训练集 source-channel 的真实 $\mu_{\rm obs,a}$ covariance 中取 top-PC / data-tangent direction：

$$
\delta_{\rm data} = \alpha u_k,
$$

并调整 $\alpha$，使它和 Arm A 有完全相同的 Mahalanobis norm：

$$
|\delta_{\rm data}|_{S_{\rm ref}^{-1}} = |\delta_{\rm ref}|_{S_{\rm ref}^{-1}}.
$$

这样只增加很少计算，却能回答一个非常关键的问题：

> **FM 是完全不传跨通道扰动，还是只不响应目前这种 $S_{\rm ref}$-shaped 人工方向？**

---

## 一次实验就能得到下面的裁决

### 情况 1：刚出 Mixer 就没了

如果：

$$
G^{mix}_{off}\approx0
$$

而 Experiment 1 已经证明 mixer 在 synthetic teacher 上有能力，

那么说明：

$$
\boxed{\text{真实 FM 学到的 mixer 映射并没有在当前局部方向上建立有效 source→target Jacobian}}
$$

此时再比较两种 perturbation：

- 若 $G^{mix}_{data}\gg G^{mix}_{ref}$，则主要问题是：

    $$\boxed{S_{\rm ref}\text{ 扰动几何与 FM 学到的数据流形不对齐}}$$

- 若两者都接近 0，则更指向：

    $$\boxed{\text{FM objective / self-channel shortcut}}$$

而不是 MexHat 或 GraphMixer capacity。

---

### 情况 2：Mixer 有 off-diagonal 响应，但 velocity 没了

如果：

$$
G^{mix}_{off}>0
$$

但：

$$
G^{vel}_{off}\approx0,
$$

则 culprit 已经非常明确：

$$
\boxed{
\text{Mixer 后面的 per-channel velocity stack 把 cross-channel message 忽略/抵消了}
}
$$

这会直接证明：

> W 虽然学到了跨通道 message，但最终 velocity predictor 不使用它。

---

### 情况 3：Velocity 有，完整 rollout 后没了

如果：

$$
G^{vel}_{off}>0
$$

但：

$$
G^{roll}_{off}\approx0,
$$

则是：

$$
\boxed{\text{Flow ODE dynamics 对 cross-channel perturbation 强收缩}}
$$

这时问题不在 Mixer。

---

### 情况 4：latent forecast 明显变化，但 decoded $R$ 仍接近 0

如果：

$$
G^{roll}_{off}>0
$$

而：

$$
R_{a,b}(r)\approx0,
$$

那几乎直接证明：

$$
\boxed{\text{per-channel Decoder 吸收了 cross-channel latent shift}}
$$

也就是当前 I–L 的 DE readout 本身看不到 Flow 已经产生的 latent influence。

---

## 为什么这个实验现在比 Raw-vs-VAE 更优先？

因为 Experiment 1 已经证明：

$$
\text{GraphMixer capacity}\approx\text{正常}.
$$

但你现在连：

> **perturbation 到底有没有穿过真实训练后的 Mixer**

都还不知道。

直接去做 Raw-vs-VAE 会跨过这一层，仍然可能无法解释为什么最终 $R$ 是对角的。

而这个逐层审计：

- 不重训 VAE；
- 不重训 FM；
- 不重训 Mixer；
- 不需要 128-source full DE matrix；
- 可以只跑 8–16 个代表 source；
- 一次就能把问题定位到 **Mixer局部方向 / velocity stack / ODE / Decoder / perturbation geometry** 中的某一级。

---

## 最小执行规模

我建议：

- 8 个代表 source：

    - frontal / central / temporal / parietal / occipital 分散取；

- 每个 source 看全部 127 个 off-diagonal target；

- 500–1000 个 train/val windows；

- $r$ 只跑：$0.5\,r_{\max},\quad r_{\max}$

- 2 类 perturbation：$\delta_{\rm ref},\quad\delta_{\rm data}$

- 不需要大量 $K/P$，诊断阶段每类 4–8 directions 足够。

最终只需要一张表：

| 层 | $G_{\rm diag}$ | $G_{\rm off}$ | off/diag | data/ref |
|---|--:|--:|--:|--:|
| Mixer output | | | | |
| Velocity output | | | | |
| Final latent | | | | |
| Decoded response | | | | |

然后找出：

$$
\boxed{
\text{off/diag 第一次从明显非零跌到接近 0 的位置}
}
$$

**那一层就是下一阶段真正应该修改的对象。**

所以基于 Experiment 1，我不会先跑 M1 3000-step tiebreaker，也不会马上重训 W-only Flow。**唯一最推荐的下一实验就是这次 frozen-model layerwise perturbation transmission audit。**
