# DYSIB-01-v2.2：paper-faithful 窗集合 DySIB 训练 + 表征评估（08-19-dysib-01-v22）

> 任务：按 DySIB 原论文（Eq.6–14、Fig.1、App.A1/A2、C2、C4）实现窗集合版 DySIB，
> 训练 d∈{32,128} 两臂（单 seed=42），在归档 8881 对齐窗上完成 G0–G5 表征探针评估。
> **本阶段只做训练与表征评估，不做任何扰动实验。**
> paper-faithful 声明：帧=128×128 窗（≈0.5s）、窗集合样本构造（Eq.6）、共享帧编码器
> Φ + 集合统计头、δ-predictor（Eq.8–10）、InfoNCE critic（Eq.11–12，bits 报告）、
> 损失 Eq.13–14（总 KL − β·ĨNCE，β=100）。v2.1 为样点偏移变体，与本版语义不可通约。

> [!summary] 一句话结论
> paper-faithful 窗集合版（帧=0.5s、(nF=2,ns=1) 共享窗两处复用、Eq.13–14 损失 β=100）
> 两臂同判 **ZERO_FACE**：任务本身非平凡且非捷径（预检 AUC≈0.45、raw 双窗基线
> +0.069、PCA-256 参照 +0.043——X 里**有**可读的新窗信息），critic 也学到了
> 3.2 bits 预测信息，但 μ(z) 对新窗的线性可读性 ≈ 0（Gain −0.071，CI_high≤−0.038）、
> 压缩毁掉全部可读信息（Δ=−0.045 真败，G2 首次有证据力）——预注册路由：**任务级/
> 数据级不足坐实，DySIB 线终止归档**。

## 实验目的与假设

**问题**：v2.1（样点偏移任务）G1 干净失败（DEBUG-FACE）。paper-faithful 版换掉两个
可疑自由源：(a) 任务面——未来窗与观测窗共享 127/128 样本的近平凡近微分，换成窗集合
平移 ns=1 窗（0.5s）的真实预测任务（App.C2：共享窗以不同拼接位置复用，预测非平凡）；
(b) 损失面——v2.1 的 NCE+KL/β（β=10）换成论文的 KL_total − β·ĨNCE（β=100、KL 不归一、
NCE 不除 d）。问题不变：**预测信息目标（DySIB）能否在压缩约束下把窗口预测所需统计量
（d 维）学出来，且优于不压缩的原始窗历史**（G1 主判）。

**设计**：帧编码器 Φ 无 softmax attention（temporal conv stem + 时间池化 + mexhat 图
消息传递通道混合 K=2）；每对编码 nF+ns=3 窗、共享窗单次编码两处复用；负样本 15 same
（并集跨度不重叠 + 间隔 ≥2 窗）+ 15 cross（候选 31，MI 天花板 log2(31)≈4.95 bits）；
每臂单 seed=42 + 预注册仲裁规则。

## 预注册块（frozen before the registered run）

### 判决规则（gate 表逐字冻结，与 DySIB-EEG v2.2-10 一致）

```
G0 泄漏：shuffle R² |值|<0.01 或 CI 含 0；
G1 主判（cross-subject）：Gain_b = R²(x_{新窗,b}←z_x) − R²(x_{新窗,b}←x_obs,b)
  （shuffle 地板 + 被试层 bootstrap 1000）：CI_low>0，实用目标 ≥+0.02；
  目标时点契约：z_x 概括 X，预测 X 之后第一个新窗 F_{n+nF} 的内容；
G2 压缩预测无损：Δ_b = R²_b(z_x) − R²_b(PCA-256 raw 参照探针)：CI_low>−0.02；
  α 网格 logspace(-2,5,14)；16384 维 raw 探针降为描述项；

```

## 分析与结论

只报预注册框架内的事实性读法，判读留给讨论：

1. **G1 干净利落地复现了 v2.1 的失败模式，且这次排除了"任务太平凡"解释**：预检
   （AUC≈0.44–0.45）显示窗级任务无慢态捷径；训练期任务确实非平凡（ĨNCE 从 <0 学到
   3–4 bits、same-acc 0.69 有真实学习曲线）；raw 域基线（B=+0.069、PCA-256=+0.043）
   证明 X 中**存在**可线性读取的新窗信息。但 z_x 对新窗的线性可读性两臂双 split
   均 ≈ 0（within 也 ≈ 0，非被试墙）。
2. **G2 首次给出有证据力的判决**：v2.1 的 G2"过"是地板驱动的（参照探针自身 −5.5）；
   v2.2 的 PCA-256 参照自身 +0.043（CI_low>0），Δ=−0.045 真败——**瓶颈压缩丢掉了
   raw 域可读的全部新窗信息**。
3. **"强 predictor 弱表征"守卫的读数**：critic 分类型准确率 cross(0.91) ≫
   same(0.69)——cross 负样本仍是被试判别性的（跨被试 z_y 更容易排除），与 G4 的
   "μ 无被试指纹"并存：判别可经由 ℓδ/μδ 或 z_y 的分布几何实现，不经 μ 的被试信息。
4. **预注册分支落点**：ZERO_FACE（G1 CI_high<0）→ 任务级/数据级不足坐实，DySIB 线
   终止归档。结合 2/3：失败更可能在"InfoNCE+δ-predictor 目标对 EEG 窗集合的
   充分统计量学习"（critic 用捷径统计量解任务而不经 μ），而非任务本身不可解
   （raw 基线可解一部分）。
5. MI 3.23 bits（d32）说明 z_x 与 z_y 之间确有可观的预测信息——但这些信息在 μ 的
   线性读出中不可见（G1≈0），即"信息在 z 里但不在 μ 的线性几何里"。

## 诚实警示（Honest caveats）

1. **单 seed**：每臂 seed 42 单跑，训练方差未量化；G1 的 CI 为评估侧 bootstrap
   （被试层），不含训练种子方差。仲裁规则未触发（两臂 CI_low=−0.094/−0.093 远离
   ±0.005 带且 CI 不含 0），按预注册**未跑第二 seed**——若按 v2.1 的多 seed 支持
   复制（≥10 seeds）可能改变 MI/G5 的读数，但不改变 G1/G2 的量级（点估计 −0.07
   远离全部阈值）。
2. **负样本偏差（EEG 适配）**：15 same + 15 cross = 31 候选 vs 论文 B=1024，MI
   天花板 log2(31)=4.954 vs ~10 bits——ĨNCE 绝对值与论文不可直接比较。本次 MI 峰值
   3.23 bits 未贴顶（<4.8），加候选数的 contingency 未启用。
3. **两臂 ≠ 完整 sweep**：MI–d/R²–d 仅两点（d32/d128），且 d↑ MI↓ 与论文
   App.C4"过参数化降方差"预期相反——该读数是单 seed 的，不足以断言 d 趋势。
4. **G3 数值溢出**：随机 rollout h≥16 出现 nan/inf（ℓδ 尾部大方差），曲线在

### Addendum 诚实警示

1. 单 seed=42 训练（沿用 v2.2 未量化的训练方差）；探针侧 MLP 为单种子（seed 11/12
   冻结），非线性结论以 RF/MLP 双家族一致为支撑。
2. RF 探针固定 λ=1e-3（论文 App.A3 逐字、无 α 选择）在 512 特征上有系统性过拟合
   偏负；MLP 亦轻度过拟合——两者一致远离 +0.01 线，不改变 BR-B 判定。

   是"是否存在非线性读出"，非论文复刻）。
4. H2/H5 容差执行偏差：H2 由设计值 1e-4 校准为 rtol 1e-3/atol 5e-3（归档 μ 为 GPU
   TF32 编码，CPU 重编码设备数值 ~2e-3）；H5 由 1e-9 校准为 1e-6（BLAS 末位 2.7e-9/
   3.4e-8）——首次注册读出在 H5 按设计中止（零产物），校准后完整重跑为注册产物；
   管线同一性由 H3 精确相等与 H4 逐位一致独立锚定。事故与偏差记录于任务
   implement.md 与 verdict `hard_checks`。
5. P3b 的 d128 frozen −11.7 为预测幅度发散的描述性读数（μδ 过冲），不进任何分支。
